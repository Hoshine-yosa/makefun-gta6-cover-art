# Neon Coast Cover Studio

Turn a photo and a caption into GTA 6-style poster cover art: multi-panel layouts, bold lettering, Vice City sunset and neon colour grades. Runs offline in a desktop browser from its own static files — your photos never leave the machine. Export PNGs at 1080×1080, 1080×1350 and 1920×1080.

Open `app/index.html` in Chrome. Upload a photo, pick a layout and grade, drag to crop, edit the caption, and export.
